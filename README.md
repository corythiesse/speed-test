# speed-test

Среднее время запроса учитывает только успешную попытку, без неудачных попыток и пауз. Общее время и средняя скорость учитывают все затраты времени, включая повторы и ожидание. В объём входят только успешно скачанные ответы.

## Запуск

Клонируйте репозиторий или скачайте файлы проекта:

```bash
git clone <URL-репозитория>
cd internet-speed-check
```

Передайте URL ресурса, который нужно скачать 10 раз:

```bash
node index.js https://example.com/large-image.jpg
```
